# Interoperability

**Design goal:** Users must be able to move work between Veyra and other game-development tools. Veyra must not lock content in.

## Required direction

- **FBX** support for meshes, materials, and animation (import/export)
- Additional open interchange formats as needed (for example **glTF**)
- Clear import/export paths so creators can switch tools freely

## Placement on the roadmap

This belongs with the **later asset pipeline / 3D work**, not the current Phase 2 2D runtime foundation.

It is already recorded in:
- `docs/ROADMAP.md` (Later phases)
- `docs/MANAGER_NOTES.md` (Decision log, 2026-11-09)
