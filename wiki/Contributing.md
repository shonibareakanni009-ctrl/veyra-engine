# Contributing / Project roles

## Ownership

- **Owner / code:** Akanni — writes and owns all production code
- **Manager:** Aether — direction, roadmap, progress tracking, quality gates, documentation, accountability

The manager does **not** write production engine code.

## How progress is tracked

1. Plans are written before big changes
2. Work is verified (CI and/or manual tests)
3. Status only changes after evidence exists
4. Everything important is documented under `docs/`

## Priority order (manager roles)

Highest focus:
- Roadmap & priorities
- Progress tracking

Also active:
- Quality standards
- Decisions
- Process
- Reality checks
- Accountability

Vision and architecture are protected but lower priority than tracking delivery.

## Branches and reviews

Prefer feature branches and pull requests for meaningful changes. Issues may be used for tracked work items.

See also `docs/MANAGER_NOTES.md`.
