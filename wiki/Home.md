## What is Veyra?

Veyra is an independent game-engine project focused on a native **2D editor and runtime**, with a longer-term path to **3D** and cross-platform tools. The foundation is **C++20**.

- Desktop editor: Qt 6 Widgets
- Runtime: Qt-free (SDL3)
- Scene format: versioned JSON `.vscene`
- First distribution target: Windows x64

## Project principles

1. **Working code over plans** — a milestone is not done until it is verified.
2. **Honest status** — no claiming features that do not exist yet.
3. **Akanni owns all production code** — manager handles direction, tracking, and documentation.
4. **Users must not be locked in** — interoperability (e.g. FBX) is a design goal.
