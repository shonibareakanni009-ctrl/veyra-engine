01 — THE ENGINE

One engine.
More ways to create.

Veyra is being developed as a cross-platform home for 2D and 3D game creation. The foundation is growing one tested system at a time.

▦

Visual creation

A desktop editor designed to bring scenes, objects, assets, and project tools together in one workspace.

⌘

Code with freedom

A C++20 engine foundation with a planned stable API and carefully evaluated scripting integrations.

◎

Reach more platforms

Windows, Linux, Android, and browser experiences are part of the long-term cross-platform direction.
